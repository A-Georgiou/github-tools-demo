# GitHub Tools Demo

This repository contains various demo applications and tools:

- **chess.html** - Interactive chess game with a basic UI
- **chart.html** - Interactive data visualization chart
- **dashboard.jsx** - React dashboard component
- **collatz_conjecture.py** - Python implementation of the Collatz Conjecture
- **process.js** - Node.js process example
- **animation.svg** - SVG animation demo
