# GitHub Tools Demo

A demonstration repository showcasing various GitHub API capabilities and mathematical algorithms implementation.

## Overview

This repository serves as a testing ground for GitHub API integration and contains implementations of mathematical algorithms and data visualization components.

## Contents

### Mathematical Algorithms
- **`collatz_conjecture.py`** - Implementation of the Collatz (3n + 1) conjecture sequence generator
- **`goldbach_conjecture.py`** - Implementation of Goldbach conjecture demonstration (see [Issue #2](https://github.com/A-Georgiou/github-tools-demo/issues/2))

### Data Visualization
- **`dashboard.jsx`** - Interactive React dashboard component with data visualization and controls
- **`chart.html`** - HTML-based interactive chart with real-time data updates
- **`process.js`** - Node.js data processing script with statistics generation

### Security Examples
- **`vulnerable_example.py`** - Intentionally vulnerable code for security testing purposes

### Assets
- **`animation.svg`** - Sample SVG animation file

## Usage

### Running the Mathematical Scripts

**Collatz Conjecture:**
```bash
python3 collatz_conjecture.py
```

**Goldbach Conjecture:**
```bash
python3 goldbach_conjecture.py
```

### Data Processing
```bash
node process.js
```
