# GitHub Tools Demo

A demonstration repository showcasing various code examples with comprehensive test coverage.

## Contents

- **collatz_conjecture.py** - Python implementation of the Collatz conjecture sequence generator
- **vulnerable_example.py** - Security demonstration with intentional command injection vulnerability
- **process.js** - Node.js data processing script with statistics calculations
- **dashboard.jsx** - Interactive React dashboard component with data visualization

## Testing

This repository includes **80 comprehensive tests** with high test coverage:

- ✅ **30 Python tests** (70% coverage) - pytest
- ✅ **50 JavaScript/React tests** (100% coverage) - Jest

### Quick Start

```bash
# Install dependencies
pip install -r requirements.txt
npm install

# Run all tests
pytest                    # Python tests
npm test                  # JavaScript/React tests

# View coverage reports
pytest --cov              # Python coverage
npm run test:coverage     # JavaScript coverage
```

See [TEST_COVERAGE.md](TEST_COVERAGE.md) for detailed test documentation.
